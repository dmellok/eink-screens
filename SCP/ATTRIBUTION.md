## Excluded from the ranking

The set is the top 100 by community rating, with the following entries skipped on content grounds and backfilled from below the cut. This is an editorial judgement, not a property of the source data — the line drawn was entries whose core premise is child abuse or sustained torture.

| Item | Reason |
| --- | --- |
| SCP-3999 | extended graphic psychological and bodily torment of one person |
| SCP-1730 | sustained graphic torture and mutilation throughout |
| SCP-231 | core premise is implied ongoing sexual abuse of a child |
| SCP-1981 | core content is graphic mutilation footage |
| SCP-2718 | premise is eternal conscious agony; widely flagged as the most distressing entry on the site |
| SCP-4666 | core premise is child abduction, torture and family killing |
